# Paso 9 · Revisión y firma final

Es la última pantalla de la etapa 4 de 5. Dice: «Revise el documento y seleccione dónde recibir el código de firma».

## Qué es lo que se firma

La tarjeta «Documento para firmar» muestra la **Solicitud de Seguros y el Formulario de Identificación de Persona Física (FIPF)**. Es un **documento unificado** que contiene los datos y las declaraciones que usted dio. Se firma **en un solo acto**, con una sola firma. Mientras no firmó, el documento figura como «Pendiente de firma»; después, como «Firma registrada».

Antes de firmar puede abrir el documento completo con **«Ver documento completo · Solo lectura»**. Solo se puede leer.

Hay dos enlaces útiles: «Coberturas, exclusiones y condiciones» y «Aviso de privacidad».

## Cómo se firma, paso a paso

1. Se elige el **canal** donde recibir el código: «WhatsApp verificado» o «Correo electrónico confirmado». La pantalla explica que recibirá un **código de un solo uso** (un número que sirve una sola vez y por poco tiempo) para realizar la firma electrónica.
2. Se marca la casilla de aceptación, que empieza con «Declaro que revisé y acepto…». El texto completo está en la casilla.
3. Se toca **«ENVIAR CÓDIGO DE FIRMA»**. La pantalla dice «Enviamos un código de firma a» y el canal elegido.
4. Aparece la tarjeta «Código de firma», que pide el código de un solo uso. Tiene un reloj («El código vence en»).
5. Se toca **«FIRMAR Y CONTINUAR»**. Mientras se registra, la pantalla dice «Firmando…».
6. Si todo sale bien: «Su firma quedó registrada» y luego «Le llevamos al pago…».

El código de firma **es distinto** del código que se usó para verificar el WhatsApp.

## Otras opciones

- **Reenviar código.** Se puede pedir otro; hay una cuenta regresiva antes de poder hacerlo. Cuando llega el nuevo, la pantalla avisa «Código reenviado» y recuerda: **use solo el último código que recibió**; el anterior deja de valer.
- Si vence el código, o se equivoca varias veces, hay que pedir uno nuevo (ver «Qué significan los mensajes del código»).

## El aviso más importante de la pantalla

La pantalla, en el recuadro «Importante», dice: **después de firmar tendrá 10 minutos para pagar. Si el plazo vence, el trámite caduca sin ningún cobro.** Por eso conviene tener listo el medio de pago antes de firmar.

## Mientras se prepara el documento

Al llegar a esta pantalla puede verse «Estamos cerrando su Solicitud y el FIPF…». Si todavía no está listo, el aviso dice que debe esperar unos segundos y volver a intentar.

## Nunca comparta el código

No comparta el código de firma con nadie ni lo escriba en este chat.

Si su consulta es sobre el contenido del documento, las coberturas o las condiciones, comuníquese con la atención oficial de Interseguros.
